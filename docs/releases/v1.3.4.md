# At-Pet v1.3.4

Windows 正式版，从 `main` 分支构建，提供 AMD64 与 ARM64 便携包。

## 新增与优化

- Agent 接入页采用可搜索卡片，集中显示连接状态、桌宠绑定、配置操作与安装指引。
- 一键配置已选 Agent 的 hooks：支持 Claude Code、Codex、WorkBuddy、Command Code、Qwen Code 和 OpenCode V2。保留原设置与第三方 hooks，修改前备份，重复配置不重复添加。
- Codex、DeepSeek Harness、GitHub Copilot 的插件指引对接 At-PetAdmin 组织中的独立仓库；其他 Agent 提供插件或手动接入说明。
- 设置新增“获取更新”，分别查询正式版和测试版，并按 Windows AMD64／ARM64 提供下载入口。
- 设置窗口标题栏新增最小化按钮，优化明暗主题的勾选状态显示，补齐中文文案。
- 并发 Agent 会话轮流展示，合并高频工具事件，优先呈现权限请求与错误。
- 新增投篮小游戏：右键开启，拖动并向篮筐甩出桌宠，从上向下穿过篮圈即可得分。
- 本地 API 增加独立客户端认证、请求归属检查、资源限制，以及事件排序、去重和终态保护。

## 升级注意

**从 v1.3.3 或更早版本升级时，请同步更新 Agent 发送端。除 `/health` 外，本地 API 现在必须认证。**

Node／TypeScript 集成须将 `client-auth.mjs` 放在入口脚本旁。Claude 原生 HTTP hooks 需要为启动 Claude Code 的进程配置 `AT_PET_API_TOKEN_CLAUDECODE`；使用本次内置的一键命令 hook 配置时，认证助手自动读取该 Agent 的本地凭证。

部分独立插件仍可能使用旧版 API，请按[认证迁移说明](https://github.com/At-PetAdmin/At-Pet/blob/v1.3.4/docs/local-api-security.md)检查兼容性。同一 Agent 的直接 hooks 与插件请选择一种，避免重复发送事件。配置后重启 Agent，并按其要求审核 hooks。

凭证仅保存在本机当前用户的数据目录，不随发行包发布；同一系统用户下运行的恶意程序仍可能读取该用户的凭证。

## 下载

- `At-Pet-windows-amd64.zip`：Intel／AMD 64 位 Windows 10/11。
- `At-Pet-windows-arm64.zip`：Windows on ARM；需要时先运行包内 `vc_redist.arm64.exe`。
- 两个包分别提供 `.sha256` 校验文件，并由 GitHub Actions 生成构建来源证明。

退出正在运行的 At-Pet 后解压替换程序，设置与桌宠库保存在用户数据目录中。

AMD64 包含运行健康检查；ARM64 的静态架构、签名与完整性检查不能替代 ARM64 实机验证。各 Agent 的完整会话接入仍需在其真实环境中分别验收。

## English

This stable release adds one-click Agent hook setup, searchable connection cards, organization plugin guides, separate stable/beta downloads, and a minimize button for Settings. It also includes the beta's multi-session presentation scheduler, basketball mini-game, authenticated local API, and event ordering/deduplication.

**Update installed integrations when upgrading from v1.3.3 or earlier.** Keep `client-auth.mjs` beside Node/TypeScript entry points. Native Claude HTTP hooks require `AT_PET_API_TOKEN_CLAUDECODE`; bundled command hooks discover their scoped credential automatically. See the [migration guide](https://github.com/At-PetAdmin/At-Pet/blob/v1.3.4/docs/local-api-security.md). Use either direct hooks or a plugin for each Agent.

Windows AMD64 and ARM64 portable packages include SHA-256 checksums and build provenance. ARM64 static verification does not replace testing on ARM64 hardware.
