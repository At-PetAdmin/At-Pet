# At-Pet v1.3.4-beta1

这是从 `beta` 分支发布的测试版，提供 Windows amd64 和 ARM64 便携包。

## 本次更新

- 本地 API 增加独立客户端凭证、Agent 身份绑定及权限／问答请求归属检查；全局状态、事件订阅和桌宠控制仅向管理员凭证开放。
- 增加连接数、待处理请求数量、请求超时与事件订阅积压限制。
- Agent 事件增加运行标识、顺序检查、去重和终态保留；带调用 ID 的并发工具分别记录状态，迟到事件不会回退整个会话。
- 不同客户端即使使用相同会话 ID，也分别维护会话与连接状态。
- 包含此前 beta 中的多会话展示调度、优先级抢占、通知合并及投篮小游戏。

## 升级注意

**除 `/health` 外，本地 API 现在必须认证。请同步更新已安装的桥接器。**

Node／TypeScript 集成须将 `client-auth.mjs` 与入口脚本放在同一目录。Claude 原生 HTTP hooks 需要为启动 Claude Code 的进程配置 `AT_PET_API_TOKEN_CLAUDECODE`。凭证自动保存在当前用户的本地应用数据目录，不随发行包分发。

完整迁移步骤与事件字段约定见[本地 API 安全说明](https://github.com/At-PetAdmin/At-Pet/blob/v1.3.4-beta1/docs/local-api-security.md)。旧发送端缺少运行／调用标识时，顺序保护只能提供有限保证；同一系统用户下的恶意程序仍可能读取该用户的本地凭证。

## 下载与验证

- `At-Pet-windows-amd64.zip`：常见 Intel／AMD 64 位 Windows。
- `At-Pet-windows-arm64.zip`：Windows on ARM；需要时先安装包内的 ARM64 VC++ 运行库。
- 两个包各提供 `.sha256` 校验文件，并通过 GitHub Actions 生成构建来源证明。

这是预发布测试版。ARM64 包的静态架构、签名和完整性检查不能替代 ARM64 实机验证。

## English

This beta adds per-client local API authentication, request ownership, bounded request handling, and Agent event ordering/deduplication with independent tool-call tracking. It also includes the preceding beta's event presentation scheduler and basketball mini-game.

**Upgrade installed integrations together with the app.** Keep `client-auth.mjs` beside Node/TypeScript entry points. Native Claude HTTP hooks require `AT_PET_API_TOKEN_CLAUDECODE`. See the [migration guide](https://github.com/At-PetAdmin/At-Pet/blob/v1.3.4-beta1/docs/local-api-security.md). Legacy events without source run/call IDs have limited ordering guarantees. Local credentials do not isolate hostile processes running as the same OS user.

Both Windows amd64 and ARM64 portable packages include SHA-256 checksums and build provenance. ARM64 static checks do not replace testing on ARM64 hardware.
