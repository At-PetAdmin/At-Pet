# Agent 事件调度与投篮小游戏

所有 Agent 事件先更新会话状态和任务面板，再由统一调度器决定桌宠展示内容。并发工具调用不会相互覆盖会话记录。

- 默认桌宠、每个 Agent 绑定的桌宠，以及独立子 Agent 桌宠使用各自的展示通道。
- 同一优先级的会话轮流展示，每次保持约 1.8 秒；同一会话的普通动画和消息更新合并至最多每 800 毫秒一次，保留最新状态。
- 权限请求优先于错误，错误优先于完成或取消，随后是普通工作事件。高优先级事件立即抢占。
- 会话结束或过期后从候选列表移除；已有的完成通知合并、权限对话框排队机制继续生效。调度仅控制展示，不限制 Agent 实际执行工具。

“看向鼠标”功能及其菜单和设置项已移除，历史设置不再读取。行走方向与专用方向动画仍正常生效。

右键桌宠，勾选 **投篮小游戏**：屏幕右侧出现篮筐，拖住桌宠向上甩出，释放时的方向与速度决定抛物线。桌宠中心从上向下穿过篮圈内部计一分，每次释放计一次投篮。落地后可再次拖动投篮。

右键再次取消 **投篮小游戏** 即可退出并回到开始前的位置。游戏中暂停自由走动、重力和休息；退出恢复原来的设置。隐藏桌宠或开启勿扰也会退出游戏。
